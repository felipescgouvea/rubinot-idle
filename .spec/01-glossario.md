# Glossário do Domínio

| Termo | Significado |
|---|---|
| **Vocação** | Classe do personagem: Knight, Paladin, Sorcerer ou Druid. Define estilo de combate e como os atributos evoluem. |
| **Nível (Level)** | Progressão principal do personagem. Máximo 100. Sobe ao acumular XP suficiente. |
| **XP** | Experiência. Ganha ao derrotar criaturas; determina o nível. |
| **Gold** | Moeda principal, obtida em caçadas. Usada para comprar equipamento e suprimentos. |
| **Rubini Coins (RC)** | Moeda premium, obtida jogando (tasks, Arena). Também pode ser comprada com dinheiro real na Loja Premium, mas essa compra ainda não está conectada a um meio de pagamento real. Usada para boosts e outfits cosméticos. |
| **HP / Mana** | Pontos de vida e de energia mágica. Regeneram com o tempo; HP zera → morte. |
| **Zona de Caça** | Área de caça associada a um mundo, com nível mínimo e lista fixa de criaturas que podem aparecer. |
| **Bestiário** | Catálogo de todas as criaturas do jogo, com atributos e tabela de loot. |
| **Loot** | Itens que uma criatura pode deixar cair ao morrer, cada um com uma chance própria. |
| **Task / Linked Task** | Missão de abater N unidades de uma criatura específica. As tasks de uma sala formam uma cadeia: uma só desbloqueia depois que a anterior for concluída pelo menos uma vez. |
| **Sala de Tasks** | Agrupamento de Linked Tasks em sequência, com nível mínimo próprio (ex.: "Lothlorien's Room"). |
| **Skill** | Habilidade de combate (Magic Level, Sword/Axe/Club/Distance Fighting, Shielding) que sobe por uso, não por pontos gastos. |
| **Spell** | Magia com nome, palavras mágicas reais, nível mínimo, custo de mana e efeito (dano ou cura). |
| **RTC (Rubinot Custom Client)** | Conjunto de configurações que simulam ajustes de um client customizado — cada ajuste troca um benefício por uma perda real. |
| **Boost** | Efeito temporário comprado na loja (mais XP, loot ou gold por um tempo). |
| **Mundo (World)** | Servidor temático dentro do jogo (ex.: Auroria, Bellum). Cada um tem tipo de PvP, bônus e zonas de caça próprias. |
| **Battle Pass** | Progressão sazonal por tiers, alimentada pela XP ganha em caçadas. |
| **Arena / Prestige Points / Divisão** | Sistema de batalhas PvP simuladas contra outros jogadores (reais ou bots), com pontuação e divisões (Bronze → Grão-Mestre). |
| **Highscore** | Ranking público global comparando todos os jogadores registrados. |
| **Outfit** | Aparência cosmética do personagem, comprada na loja com Rubini Coins. |
| **Equipamento** | Itens equipáveis nos slots clássicos do Tibia: elmo, arma, armadura, escudo, anel, calças, botas. |
| **Progresso Offline** | Ganhos de XP e gold calculados quando o jogador retorna após ficar fora enquanto caçava. |
