# Glossário do Domínio

| Termo | Significado |
|---|---|
| **Vocação** | Classe do personagem: Knight, Paladin, Sorcerer ou Druid. Define estilo de combate e como os atributos e skills evoluem. |
| **Promoção** | Versão avançada da vocação (Elite Knight, Royal Paladin, Master Sorcerer, Elder Druid), comprada com gold a partir do nível 20. Dobra a regeneração de HP/mana em descanso. |
| **Rook / Graduação** | O personagem começa numa fase inicial (estilo Rook/Dawnport) com vocação **provisória**. No nível 8 ele **gradua**: confirma ou troca a vocação em definitivo e recebe o kit de graduação. |
| **Nível (Level)** | Progressão principal do personagem. Sobe acumulando XP pela fórmula oficial do Tibia. Não há dead-end permanente. |
| **XP** | Experiência. Ganha ao derrotar criaturas e concluir tarefas; determina o nível. |
| **Skill** | Habilidade de combate (Magic Level, Fist/Club/Sword/Axe/Distance Fighting, Shielding) que sobe **por uso**, não por pontos gastos. Cada vocação evolui cada skill num ritmo próprio. |
| **Spell** | Magia com nome e palavras mágicas reais, nível mínimo, custo de mana (e às vezes de soul), cooldown e efeito (dano, cura, suporte, conjurar ou utilitário). |
| **RTC** | Automação de combate ("Rubinot Custom Client"): lista de prioridade de ataque (magias e/ou runas), cura automática em degraus por magia e por poção, poção de mana, prioridade de alvo e escolha de área vs. alvo único. |
| **HP / Mana** | Pontos de vida e de energia mágica. Regeneram com o tempo (dobro se promovido); HP zerado → morte. |
| **Soul Points** | Segunda "moeda" de conjuração. Toda magia que fabrica item (munição, runas) custa mana **e** soul. Soul só volta com o tempo. |
| **Gold** | Moeda principal, obtida caçando. Compra equipamento, suprimentos, bênçãos e serviços. |
| **Rubini Coins (RC)** | Moeda premium, ganha jogando (tasks, Arena) ou comprada com dinheiro real (compra real ainda não conectada a pagamento). Usada em boosts, cosméticos e conveniências. |
| **Zona de Caça** | Área de caça associada a uma cidade/mundo, com nível mínimo e lista fixa de criaturas. |
| **Bestiário** | Catálogo de todas as criaturas, com atributos, loot e progresso de abates. Preencher rende Charm Points. |
| **Charm / Charm Points** | Pontos ganhos preenchendo o bestiário, gastos em bônus passivos (Charms) aplicados às criaturas. |
| **Loot** | Itens que uma criatura pode deixar cair ao morrer, cada um com sua chance. |
| **Relíquia** | Modificador de raridade que um item de equipamento pode ter (drop exclusivo). Liberdade de design deste jogo; análogo aos Imbuements. |
| **Imbuement** | Bônus aplicável a um item de equipamento (dano elemental, vida/mana no golpe, resistência etc.), fiel ao sistema do Tibia. |
| **Task / Linked Task** | Missão de abater N unidades de uma criatura. As tasks de uma sala formam uma cadeia: cada uma só desbloqueia depois que a anterior for concluída ao menos uma vez. |
| **Sala de Tasks** | Agrupamento sequencial de Linked Tasks com nome próprio (ex.: "Lothlorien's Room"). Uma sala só abre quando a anterior é fechada por completo. |
| **Treino** | Evolução de uma skill escolhida fora do combate. Roda acelerado com o jogo aberto e continua (mais devagar) enquanto fechado. |
| **Bênção (Blessing)** | Proteção comprada com gold que reduz a perda de XP na morte e melhora o HP ao reviver. É consumida ao morrer. |
| **Stamina** | Recurso opcional (ligado pelo operador) que cai caçando e, quando baixo, reduz a XP — incentiva descanso. |
| **Boost** | Efeito temporário (mais XP, loot ou gold por um tempo). |
| **Mundo (World)** | Servidor temático dentro do jogo (ex.: Auroria, Bellum), com bônus fixos de XP/Gold e nível mínimo. |
| **Battle Pass** | Progressão sazonal (mês calendário) por tiers, alimentada por XP e missões diárias/semanais. Trilha gratuita e trilha premium. |
| **Arena / Prestige Points / Divisão** | Batalhas PvP simuladas contra outros jogadores (reais ou bots), com pontuação e divisões (Bronze → Grandmaster). |
| **Boss Zone** | Desafiar diretamente o boss de uma zona já desbloqueada, sem os monstros comuns. |
| **Presa (Prey)** | Bônus temporário de dano/XP/loot contra uma criatura escolhida. |
| **Mercado** | Negociação de itens entre jogadores por gold (habilitado pelo operador). |
| **Highscore** | Ranking público global comparando os jogadores registrados. |
| **Conquista / Título** | Marco derivado dos stats do personagem; alguns concedem um título exibível ao lado do nome. |
| **Outfit** | Aparência cosmética do personagem, com cor por região e addons, extraída do cliente oficial. |
| **Equipamento** | Itens equipáveis nos slots clássicos do Tibia: elmo, arma, armadura, escudo, anel, calças, botas, colar, munição. |
| **Progresso Offline** | Ganhos calculados quando o jogador volta após ficar fora enquanto caçava/treinava, com teto de horas e ritmo reduzido. |
