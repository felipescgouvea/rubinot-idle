# Glossário do Domínio

| Termo | Significado |
|---|---|
| **Vocação** | Classe do personagem: Knight, Paladin, Sorcerer ou Druid. Define estilo de combate e evolução de atributos/skills. |
| **Promoção** | Versão avançada da vocação (Elite Knight, Royal Paladin, Master Sorcerer, Elder Druid), comprada com gold a partir do nível 20. Dobra a regeneração de HP/mana em descanso. |
| **Rook / Graduação** | Fase inicial (estilo Rook/Dawnport) com vocação **provisória**. No nível 8 o personagem **gradua**: confirma ou troca a vocação em definitivo e recebe o kit de graduação. |
| **Nível (Level)** | Progressão principal. Sobe acumulando XP pela fórmula oficial do Tibia. Sem dead-end permanente. |
| **XP** | Experiência. Ganha em abates e tarefas; determina o nível. |
| **Skill** | Habilidade de combate (Magic Level, Fist/Club/Sword/Axe/Distance Fighting, Shielding) que sobe **por uso**. Cada vocação evolui cada skill num ritmo próprio. |
| **Spell** | Magia com nome e palavras mágicas reais, nível mínimo, custo de mana (e às vezes soul), cooldown e efeito. |
| **RTC** | Automação de combate ("Rubinot Custom Client"): prioridade de ataque (magias/runas), cura automática em degraus (magia e poção), poção de mana, prioridade de alvo, área vs. alvo único. |
| **HP / Mana** | Vida e energia mágica. Regeneram com o tempo (dobro se promovido); HP zerado → morte. |
| **Soul Points** | Segunda moeda de conjuração. Toda magia que fabrica item (munição, runas) custa mana **e** soul. Só volta com o tempo. |
| **Gold** | Moeda principal, obtida caçando. Compra equipamento, suprimentos, bênçãos e serviços. |
| **Rubini Coins (RC)** | Moeda premium, ganha jogando (tasks, Arena) ou comprada com dinheiro real (compra ainda não conectada a pagamento). Usada em boosts, cosméticos e conveniências. |
| **Zona de Caça** | Área associada a uma cidade/mundo, com nível mínimo e lista fixa de criaturas. |
| **Bestiário** | Catálogo de criaturas, com atributos, loot e progresso de abates. Preencher rende Charm Points. |
| **Charm / Charm Points** | Pontos ganhos preenchendo o bestiário, gastos em bônus passivos (Charms) aplicados às criaturas. |
| **Loot** | Itens que uma criatura pode deixar cair, cada um com sua chance. |
| **Relíquia** | Modificador de raridade de um item de equipamento (drop exclusivo). Liberdade de design deste jogo; análogo aos Imbuements. |
| **Imbuement** | Bônus aplicável a um item (dano elemental, vida/mana no golpe, resistência etc.), fiel ao Tibia. |
| **Task / Linked Task** | Missão de abater N de uma criatura. As tasks de uma sala formam cadeia: cada uma só desbloqueia após a anterior ser concluída ao menos uma vez. |
| **Sala de Tasks** | Agrupamento sequencial de Linked Tasks com nome próprio (ex.: "Lothlorien's Room"). Só abre quando a anterior é fechada por completo. |
| **Treino** | Evolução de uma skill escolhida fora do combate. Acelerado com o jogo aberto, mais lento enquanto fechado. |
| **Bênção (Blessing)** | Proteção comprada com gold que reduz a perda de XP na morte e melhora o HP ao reviver. Consumida ao morrer. |
| **Stamina** | Recurso opcional (ligado pelo operador) que cai caçando e, baixo, reduz a XP. |
| **Boost** | Efeito temporário (mais XP, loot ou gold por um tempo). |
| **Mundo (World)** | Servidor temático (ex.: Auroria, Bellum), com bônus fixos de XP/Gold e nível mínimo. |
| **Battle Pass** | Progressão sazonal (mês calendário) por tiers, alimentada por XP e missões diárias/semanais. Trilha gratuita e premium. |
| **Arena / Prestige Points / Divisão** | Batalhas PvP simuladas contra outros jogadores (reais ou bots), com pontuação e divisões (Bronze → Grandmaster). |
| **Boss Zone** | Desafiar direto o boss de uma zona já desbloqueada, sem os monstros comuns. |
| **Presa (Prey)** | Bônus temporário de dano/XP/loot contra uma criatura escolhida. |
| **Mercado** | Negociação de itens entre jogadores por gold (habilitado pelo operador). |
| **Highscore** | Ranking público global entre jogadores registrados. |
| **Conquista / Título** | Marco derivado dos stats do personagem; alguns concedem um título exibível ao lado do nome. |
| **Outfit** | Aparência cosmética do personagem, com cor por região e addons, extraída do cliente oficial. |
| **Equipamento** | Itens equipáveis nos slots clássicos do Tibia: elmo, arma, armadura, escudo, anel, calças, botas, colar, munição. |
| **Progresso Offline** | Ganhos calculados quando o jogador volta após ficar fora caçando/treinando, com teto de horas e ritmo reduzido. |
